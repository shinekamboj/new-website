# Pixel Pals Arcade

A responsive React game hub with separate kids' and grown-ups' collections, Firebase email/password signup/login, per-user Firestore profiles and game results, and an About Us footer section. It includes 13 browser games, with Phaser 4 racing and a Three.js 3D runner.

Live demo: https://new-website-50b26.web.app

## Run locally

```powershell
npm.cmd install
npm.cmd run dev -- --port 4175
```

Open `http://localhost:4175` for the Gaming Website preview.

## Automated verification

Run the browser test suite directly with Playwright CLI. Playwright's HTML/JSON reports and the per-test screenshots are generated by this command:

```sh
npx playwright test
```

The optional `npm run verify` command orchestrates a domain check, production build, and Playwright run. Screenshots, JSON results, and the HTML report are written under `evidence/`; `requirements.md` and `evidence/verification.md` record verification. GitHub Actions runs the domain check, build, and Playwright CLI on pushes and pull requests after this project is pushed to GitHub.

## Firebase Hosting

The current deployment is at https://new-website-50b26.web.app. The latest Playwright run has **20 passing tests**. Deploy locally with `npm.cmd run build` followed by `npm.cmd run deploy`. GitHub automatic deployment is paused until the repository has the Actions secret `FIREBASE_SERVICE_ACCOUNT_NEW_WEBSITE_50B26` and variable `FIREBASE_HOSTING_AUTODEPLOY=enabled`. Firebase CLI's `firebase init hosting:github` can provision the secret; never commit service-account JSON. The main verification workflow (build, tests, evidence upload) runs on pushes and pull requests independently.

Firebase Auth/Firestore integration: create an account from the header Login popup. Profiles are stored at `users/{uid}` and completed-game results at `users/{uid}/gameResults`. A real-account persistence check is manual; do not send passwords in chat.

See [requirements.md](./requirements.md) for requirements, test cases, and domain lookup notes.
