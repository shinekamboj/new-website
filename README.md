# Pixel Pals Arcade

A responsive React game hub with separate educational picks for kids and general-audience games for grown-ups. All ten sample games run locally in the browser.

Live demo: https://new-website-50b26.web.app

## Run locally

```sh
npm install
npm run dev
```

## Automated verification

Run the browser test suite directly with Playwright CLI. Playwright's HTML/JSON reports and the per-test screenshots are generated by this command:

```sh
npx playwright test
```

The optional `npm run verify` command orchestrates a domain check, production build, and Playwright run. Screenshots, JSON results, and the HTML report are written under `evidence/`; `requirements.md` and `evidence/verification.md` record verification. GitHub Actions runs the domain check, build, and Playwright CLI on pushes and pull requests after this project is pushed to GitHub.

## Firebase Hosting

The current deployment is at https://new-website-50b26.web.app. Deploy locally with `npm run build` followed by `npm run deploy`. The GitHub workflow also builds and tests before deploying on pushes to `main`; it requires the repository Actions secret `FIREBASE_SERVICE_ACCOUNT_NEW_WEBSITE_50B26`. Use Firebase CLI's `firebase init hosting:github` after GitHub CLI authentication to provision that secret automatically, or add the service-account JSON through GitHub repository Settings → Secrets and variables → Actions. Never commit the service-account JSON.

See [requirements.md](./requirements.md) for requirements, test cases, and domain lookup notes.
